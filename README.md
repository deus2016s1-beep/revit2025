# VentCalc v1.0

VentCalc — pyRevit extension для Revit 2025. Расширение выполняет аэродинамический расчёт вентиляционных воздуховодных сетей, помогает заполнить коэффициенты местных сопротивлений, проверить модель, подсветить трассу/скорости и подготовить проектный Excel-отчёт.

## Панели и кнопки

### Вентиляция

Основная рабочая панель содержит только команды для ежедневной работы:

- **Расчёт** — выполняет аэродинамический расчёт критической трассы и создаёт Excel.
- **МС** — заполняет коэффициенты местных сопротивлений для фитингов, решёток, зонтов и клапанов.
- **Трасса** — включает или выключает красную подсветку последней рассчитанной критической трассы.
- **Скорости** — подсвечивает воздуховоды по диапазону скоростей: ниже нормы, норма, выше нормы.
- **Настройки** — настраивает запас давления, шероховатость, диапазон скоростей и создание Excel.

### Сервис

Диагностические команды вынесены отдельно:

- **Аудит** — показывает кандидаты критической трассы и расшифровку местных сопротивлений последнего расчёта.
- **Проверка** — показывает предупреждения по воздуховодной сети без изменения модели.
- **Очистить** — снимает подсветку VentCalc с элементов активного вида.

### Зарезервированные панели

Панели **Отопление**, **Водоснабжение** и **Водоотведение** зарезервированы для будущих инженерных инструментов.

## Как пользоваться

1. Нажмите **МС**, проверьте рекомендуемые значения и запишите коэффициенты местных сопротивлений в комментарии элементов.
2. Выберите конечный элемент трассы: вентилятор, выброс, конечный воздуховод или оборудование.
3. Нажмите **Расчёт** и проверьте таблицу в pyRevit output.
4. Откройте созданный Excel-файл на рабочем столе.
5. Нажмите **Трасса**, чтобы включить или выключить подсветку критической трассы.
6. Нажмите **Скорости**, чтобы подсветить воздуховоды по диапазону скоростей.
7. Нажмите **Настройки**, чтобы изменить запас давления, шероховатость, диапазон скоростей и режим создания Excel.
8. При необходимости откройте **Аудит** или **Проверка** на панели **Сервис**.

## Excel

Excel по умолчанию сохраняется на рабочий стол пользователя с именем вида:

`VentCalc_Aero_YYYYMMDD_HHMMSS.xlsx`

Внутри файла остаются русские проектные заголовки и расчётные участки.

## Настройки

VentCalc сохраняет настройки рядом с extension в файле `ventcalc_settings.json`.

- **Запас давления, %** берётся из настроек и применяется в расчёте итогового давления.
- **Минимальная скорость** и **Максимальная скорость** не влияют на аэродинамический расчёт давления. Они нужны только для **Проверки** и команды **Скорости**.
- Коэффициенты местных сопротивлений сохраняются в `ventcalc_zeta.json`.
- Последний результат расчёта сохраняется в `ventcalc_last_result.json` для аудита и подсветки трассы.

## Совместимость

- Revit 2025.
- pyRevit / IronPython 2.7.
- Без внешних табличных библиотек, современных Python-конструкций и Excel COM.
